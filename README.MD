# 📊 Customer Churn Analysis Project

## 🎯 Objective
To analyze customer behavior and identify key factors causing customer churn.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📁 Project Structure
- data/ → Dataset files  
- notebooks/ → Analysis code  
- images/ → Charts & visuals  

## 📊 Key Insights
- Month-to-month customers churn the most  
- High monthly charges increase churn risk  
- New customers leave faster than old customers
